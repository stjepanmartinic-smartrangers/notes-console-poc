Notes Console

Shareable POC. Parents stay in this console. Children are the notes that land on packages, services, locations, group tours, and itineraries. Nothing here is written to TMDev.

Permission set Notes Console User
Create, edit, and delete. Assigned by you on TMDev.

Parent notes

Click a parent to show its child notes underneath. Search matches a parent when the parent or any child matches. Inactive children stay in the list so you can see Active = false. They still appear in the Package Search simulation.

The parent never appears here. It has no lookup to the record. Active is a subscriber field: the Itinerary and Group Tour tabs hide inactive notes, and Package Search, Service, and Location still show them.
